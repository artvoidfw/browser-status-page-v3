# 🌌 CosmicTab v3 - Browser Status Page (Yeni Səhifə Genişlənməsi)

Müasir, kosmik telemetriya dizaynlı, **100% saf və qradientsiz (Zero Gradients)** yeni səhifə (New Tab) brauzer genişlənməsi.

Hazırlayan: [artvoidfw](https://github.com/artvoidfw) | [Artvoid Portfolio](https://artvoid.vercel.app/)

---

## 🚀 Brauzerə (Brave, Chrome, Edge, Opera) Necə Əlavə Etməli?

1. Brauzerinizin ünvan sətrinə daxil olun:
   - **Brave üçün:** `brave://extensions`
   - **Chrome üçün:** `chrome://extensions`
   - **Edge üçün:** `edge://extensions`
2. Sağ yuxarı küncdəki **"Developer mode" (Tərtibatçı rejimi)** açarını aktiv edin.
3. Yuxarı solda yerləşən **"Load unpacked" (Paketlenməmiş yüklə)** düyməsini sıxın.
4. Açılan pəncərədə bu layihə qovluğunu (**`browser-status-page-v3`**) seçin.
5. Brauzerdə yeni səhifə (`Ctrl + T`) açın və kosmik səyahətdən zövq alın! 🎉
